# Phoenix User UI V0.1 — Acceptance Readiness

## Implemented in the User UI branch

- Persistent Phoenix Core header and tenant context.
- Dynamic authorized module navigation from the Core/module boundary.
- Home, My Work, Notifications and Profile workspaces.
- Production module workspace and production-order workflow integration.
- Core service adapter with authenticated HTTP boundary.
- Client-side security/integration checks.
- Security & Integration workspace.
- Runtime integration test runner/workspace added; wiring into `app.js` remains pending.

## Acceptance gates

| ID | Gate | Status |
|---|---|---|
| AUTH-01 | Unauthenticated request rejected by Core | Runtime verification required |
| AUTH-02 | Authenticated user receives user/tenant context | Runtime verification required |
| AUTH-03 | Invalid/expired session handled safely | Runtime verification required |
| TEN-01 | Tenant context present in User UI | Implemented; runtime verification required |
| TEN-02 | Cross-tenant record access denied by Core | Runtime verification required |
| MOD-01 | Only authorized modules are exposed | Implemented at UI boundary; runtime verification required |
| MOD-02 | Unauthorized module route/data access denied | Runtime verification required |
| PROD-01 | Business action remains server-authoritative | Runtime verification required |
| PROD-02 | Failed action produces no false success | Runtime verification required |
| DATA-01 | User UI has no direct DB access | Implemented by architecture; runtime/code review required |
| DATA-02 | API failure produces safe UI state | Implemented for current Core-backed workspaces |
| NAV-01 | Unknown route fails safely | Implemented |
| NAV-02 | Module failure does not destroy shell | Implemented for current module rendering boundary |
| SESS-01 | Logout/session termination works end-to-end | Runtime verification required |

## Release rule

V0.1 is not declared production-accepted until the mandatory runtime gates AUTH-01/02/03, TEN-02, MOD-02, PROD-01 and SESS-01 pass against the actual integrated Phoenix Core runtime.

No client-side check in this document replaces server-side authentication, authorization, tenant isolation, transaction validation or audit controls.
